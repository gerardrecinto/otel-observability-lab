otel-observability-lab

A small checkout service sends traces, metrics and logs over OpenTelemetry to a Collector. The Collector routes each signal to its own backend: Mimir for metrics, Loki for logs, Tempo for traces. Grafana sits in front. Every number on this page was read back from those backends.

What it looks like

How the signals flow

Metrics: asked of Mimir with PromQL

Requests per second

sum(rate(checkout_requests_total[1m]))

Error ratio

errors / requests, the service fails 1 in 5 on purpose

p95 latency (seconds)

histogram_quantile(0.95, ...)

Logs: asked of Loki with LogQL

{service_name="checkout-demo"} |= "checkout failed"

Each line carries the trace_id and span_id of the request that produced it, so a log line leads straight to its trace.

Traces: the trace that the first error log points at

Something that bit me

The p95 was off by two orders of magnitude. The first version reported a p95 of 4.75 seconds for requests that took about 40 milliseconds. The OpenTelemetry SDK's default histogram buckets are written for milliseconds (0, 5, 10, 25 ... 10000), and my metric is in seconds, so every request fell into the first bucket and the quantile was interpolated inside it. The fix is a View with buckets in seconds, and the test now fails if p95 is not under one second.

Run it yourself

git clone https://github.com/gerardrecinto/otel-observability-lab
cd otel-observability-lab
./scripts/test.sh            # starts the stack, waits for data, checks every backend
open http://localhost:3000   # Grafana, no login
python3 scripts/record.py    # rewrites docs/data.json, the data on this page
docker compose down -v

Needs Docker with Compose. About three minutes the first time.

Not covered

One node, local disk, no authentication, no retention limits, no alert rules and no Kubernetes deployment. The service is synthetic, so the numbers show the pipeline works, not how a real checkout behaves. Sampling, multi-tenancy and long-term storage in object storage are the next things a real deployment needs.
